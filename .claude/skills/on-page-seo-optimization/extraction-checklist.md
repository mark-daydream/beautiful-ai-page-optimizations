# Extraction Checklist

## Target page

- [ ] Title, meta description, canonical
- [ ] H1, H2 hierarchy (ordered)
- [ ] Section manifest: name, eligibility (`generic`|`branded`|`locked`), word count band
- [ ] **Full body copy of every section, verbatim** (not just headings) — needed so Tab 1 & Tab 2 can render complete content for changed AND unchanged sections
- [ ] Primary + supporting keyword counts
- [ ] Internal links (cannibalization flags)
- [ ] Schema types present
- [ ] Trust signals, existing FAQ list (verbatim)

## Competitors (matched types only)

- [ ] URL, rank, page type
- [ ] Title/H1 keyword placement
- [ ] Primary keyword instance count (estimate)
- [ ] Section types: definition, how-it-works, FAQ, comparison table
- [ ] PAA questions answered on page

Score: title placement, H1 match, FAQ, definition in first 100 words, keyword density, schema, trust.
